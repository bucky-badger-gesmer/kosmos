### Story prompts

2. **A hard bug across the stack** — front-end symptom, root cause elsewhere. Shows debugging + system thinking.

5. **Mentoring or being mentored** — this is a *mentored role* with a *dedicated mentor*, so show you value the learning relationship in both directions.
6. **Working with product/design** — breaking a fuzzy feature into scoped work, pushing back constructively on scope. Pairs perfectly with Dan (PM).
